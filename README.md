# Emre Ocak

Bu proje, HTML kullanılarak hazırlanmış basit bir kişisel tanıtım sayfasıdır. Sayfada Emre Ocak’ın profil fotoğrafı, özgeçmişi, eğitim bilgileri, yetenekleri, iletişim bağlantıları ve Google Maps üzerinden konum bilgisi yer almaktadır.

## İçerik
- Ad Soyad bölümü
- Profil fotoğrafı
- Özgeçmiş
- Eğitim geçmişi
- Yetenekler
- İletişim bağlantıları
- Google Maps ile Zürih konumu

## Kullanılan Teknolojiler
- **HTML5**
- CSS stilleri
- Google Maps

## Amaç
HTML yapılarını, div–section kullanımını ve stil eklemeyi pekiştirmek için hazırlanmıştır.
